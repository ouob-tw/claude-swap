# Session 狀態面板規格

來源：2026-10-08 本輪使用者對話。

使用者要求：「可以做一個控制面板，讓我查看狀態嗎？用現有的改？」
使用者選擇：「直接擴充現有終端機面板」。

- 在現有 cswap 終端機面板新增 Session／快取狀態頁，原本帳號額度頁保留。
- 顯示目前帳號、自動切換背景服務狀態、閒置預選是否啟用、5HR 候選上限與最近切換。
- 顯示每個已追蹤 Session 的工作目錄名稱、忙碌／閒置／關閉狀態、快取預估到期時間及剩餘時間；資料缺失不可顯示成已過期。
- 顯示 Session 判斷是否允許閒置預選，以及被擋住的原因。這只代表 Session 條件，不保證帳號額度符合切換條件。
- 狀態自動更新，使用既有切換規則和快取觀測資料，不另啟動自動切換程序、不發起額外額度查詢或自動切帳號。
- 面板讀取失敗須明示資料不可用，不能默默保留舊資料當作最新狀態；可返回原有面板。
- 快取到期時間為預估，不宣稱伺服器已確認清除。

驗證：隔離資料測試資料呈現、未到期／已到期／未知狀態、開啟／更新／返回頁面與讀取失敗；既有切換及面板測試維持通過。

2026-10-09 小螢幕調整：主畫面保留帳號、服務、Session 阻擋原因與精簡表格；設定、最近切換及快取說明移至可點擊的 Help 彈窗，並提供懸浮提示。完整列內容與到期時間可選取後按 Enter 查看。窄螢幕隱藏 Session ID 欄並限制欄寬，減少上下留白，保留未知與讀取失敗提示。
